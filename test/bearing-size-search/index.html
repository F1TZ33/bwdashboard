Bearing Size Search

Search bearing references by bore / ID, OD and width. Built in the BW Playbook module format: local assets, no fetch calls, no GitHub dependency.

Starter dataset: this module currently contains only a small starter/structure dataset and NTN category references visible from the Bearing Finder page. Add your real BW dimension catalogue into assets/bearing-data.js to make this a full production search.
